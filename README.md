# Learniverse Hub

Modern, responsive e-learning platform website for all age groups, featuring a clean dashboard-style layout with a prominent hero section, category-based video course browsing, personalized recommendations, and clear sections for popular, trending, and newly uploaded courses. Friendly yet professional design with a vibrant blue, white, and soft orange color palette, rounded cards, engaging thumbnails, intuitive navigation, and readable sans-serif typography, plus a dedicated teacher portal for uploading courses, managing content, and showcasing expertise across diverse subjects.
